A one-line entry for the make.fun bounty "Out of Tokens, Mid-Sentence": the
error message an AI agent shows when it runs out of tokens mid-sentence.

Running `main.ts` writes the entry line to `entry.txt` in the directory named
by `MAKEFUN_OUTPUT_DIR` (or `./out` when unset), with no trailing newline.
